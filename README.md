# The Shot

Welcome to **The Shot**.

This project is a React-based 3D application built with Vite, Tailwind CSS, and Three.js.

## 🚀 Live Demo
The application is deployed and can be accessed live at: 
[https://theshot.antideploy.com/](https://theshot.antideploy.com/)

## 🛠️ Local Development

To run this project locally:

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```

## 📝 Technologies Used
* React
* Vite
* Tailwind CSS
* Three.js
